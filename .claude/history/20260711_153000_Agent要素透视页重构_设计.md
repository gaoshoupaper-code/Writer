# Agent 要素透视页重构 — 设计方案（冻结）

## 1. 架构快照

### 全局定位

重构 `evolution/desktop/src/pages/harness.tsx`（Agent 要素透视页）。后端数据全就绪，本次是**纯前端重写，后端零改动**。

**数据源**（两个端点，并行调用）：
- 要素数据：`GET /api/snapshots/{version}/elements` → 已封装 `getElements(version)`
- 升级数据：`GET /api/versions/{version}` → **后端已有（含 `changes` 字段），前端需新增封装 `getVersionDetail(version)`**

### 技术栈（沿用现有，不引入新依赖）

React 19 + TypeScript + shadcn `<Tabs>` + 语义化 CSS 类（globals.css）+ Tauri invoke 中继。
**不引入 diff 渲染库**——后端已算好 hunks（equal/insert/delete），前端原生渲染即可。

### 页面信息架构（冻结）

```
harness.tsx（页面壳）
  │
  ├─ 版本选择器（下拉，沿用现有，default=production）
  │
  ├─ UpgradeOverview（顶部升级总览条）
  │   ├─ 客观 diff 摘要（紧凑：哪些 agent 变了什么要素）
  │   └─ 「改动意图」可折叠区块（intent 列表，默认收起）
  │   ※ 首版本（is_bootstrap 或 parent_version=null）→ 显示"初始版本，无升级对比"占位
  │
  └─ <Tabs>（shadcn，三 Tab）
      ├─ Prompt Tab（默认）
      │   ├─ 「显示 diff」开关（Tab 内独立 state）
      │   └─ 按 agent 分段的 prompt 列表，每段标 Agent 徽章
      │       diff 开关 ON → 全文叠加高亮（equal 正常 / insert 绿底 / delete 红底）
      │       diff 开关 OFF → 当前版本全文
      ├─ Skills Tab
      │   ├─ 「显示 diff」开关（Tab 内独立 state）
      │   └─ 路径列表，标 Agent 徽章
      │       新增路径绿底 / 删除路径红底（仅 diff ON 时）
      └─ Middleware Tab
          └─ LifecycleSwimlane（泳道图）
              ├─ 表头：固定 6 列（before_agent→…→after_agent）
              ├─ 行：每个 agent 一条泳道
              │   无 middleware 的 agent → 折叠为一行摘要，点击展开
              ├─ 格子：middleware 纵向堆叠小卡片，标 Agent 徽章
              │   节点着 diff 语义色（绿/红/黄）
              └─ 点击节点 → MiddlewareDetail 展开（params/class + 懒加载源码）
```

## 3. 数据与接口契约

### 3.1 新增 API 封装（lib/api.ts）

```ts
// ── 版本详情（含升级 diff） ──
export async function getVersionDetail(version: number): Promise<VersionDetail> {
  return evoJson<VersionDetail>(`/api/versions/${version}`, { method: "GET" });
}

// ── 源码懒加载 ──
export async function fetchSource(version: number, path: string): Promise<{ path: string; content: string }> {
  return evoJson(`/api/snapshots/${version}/source`, {
    method: "GET",
    // path 作为 query param：/api/snapshots/{v}/source?path=middleware/goal.py
    // 实际用 evoJson 配合 URLSearchParams 拼，或直接拼 URL
  });
}
```

> **注意**：`fetchSource` 的 path 是 query 参数，用 `?path=${encodeURIComponent(path)}` 拼。

### 3.2 新增 TS 类型（lib/api.ts，紧跟现有 ElementsView 定义之后）

```ts
// ── 版本详情（仅本次需要的字段，其余忽略） ──
export interface VersionDetail {
  version: number;
  parent_version: number | null;
  is_bootstrap: boolean;
  change_summary: string | null;
  changes: VersionChanges;
}

export interface VersionChanges {
  agents: { agent: string; diff: AgentDiff }[];
  intent: IntentItem[] | null;
}

export interface AgentDiff {
  prompt?: { hunks: Hunk[]; summary: { added: number; removed: number } } | null;
  skills?: { added: string[]; removed: string[]; unchanged_count: number } | null;
  processors?: ProcessorChange[];
  whole_agent?: "added" | "removed";  // 仅整 agent 增删时存在，常规修改缺失
}

export interface Hunk {
  type: "equal" | "insert" | "delete";
  lines: string[];
}

export interface ProcessorChange {
  key: { hook: string; group: string };
  change_type: "added" | "removed" | "modified";
  class_change: { old: string | null; new: string | null };
  params_change: { old: Record<string, any> | null; new: Record<string, any> | null };
}

export interface IntentItem {
  target: string;        // 恒 string，缺失填 ""
  change_desc: string;
  reason: string;
  expected_up: string;
  expected_down: string;
}
```

## 4. 组件拆分（components/harness/）

| 组件文件 | 职责 | Props |
|---|---|---|
| `UpgradeOverview.tsx` | 顶部升级总览条：客观 diff 摘要 + intent 可折叠 | `changes: VersionChanges \| null`, `isBootstrap: boolean` |
| `AgentBadge.tsx` | Agent 归属徽章（小标签） | `name: string` |
| `PromptTab.tsx` | Prompt Tab：按 agent 分段，全文/diff 切换 | `agents: AgentElementView[]`, `diffs: Map<string, AgentDiff> \| null` |
| `PromptDiffViewer.tsx` | 单个 prompt 的全文 diff 高亮渲染 | `hunks: Hunk[]`, `body: string` |
| `SkillsTab.tsx` | Skills Tab：路径列表 + 增删高亮 | `agents: AgentElementView[]`, `diffs: Map<string, AgentDiff> \| null` |
| `MiddlewareTab.tsx` | Middleware Tab 容器：管理展开泳道 state | `agents: AgentElementView[]`, `diffs: Map<string, AgentDiff> \| null`, `version: number`, `hasSource: boolean` |
| `LifecycleSwimlane.tsx` | 泳道图：6 列表头 + agent 行 + 空行折叠 | `agents: AgentElementView[]`, `diffs: Map<string, AgentDiff> \| null`, `version`, `hasSource` |
| `MiddlewareNode.tsx` | 泳道格子内的单个 middleware 小卡片 + 点击展开详情/源码 | `mw: AgentElementView["middlewares"][0]`, `change?: ProcessorChange`, `version`, `hasSource` |

**页面壳** `pages/harness.tsx`（重写）：
- State：`snapshots`, `selectedVersion`, `elements`, `versionDetail`, `loading`, `activeTab`
- 并行调 `getElements(v)` + `getVersionDetail(v)`
- 渲染：版本选择器 → `<UpgradeOverview>` → `<Tabs>`（PromptTab/SkillsTab/MiddlewareTab）
- `diffs` 计算：从 `versionDetail.changes.agents` 构建 `Map<agentName, AgentDiff>`，传给各 Tab

## 7. 边缘场景与降级

| 场景 | 处理 |
|---|---|
| 首版本（is_bootstrap / parent_version=null） | UpgradeOverview 显示"初始版本，无升级对比"占位；各 Tab diff 开关无效果（无 diff 数据） |
| changes.agents 为空数组 | 总览条显示"本版本无要素变更"；各 Tab diff 开关无效果 |
| intent 为 null | 隐藏"改动意图"折叠区块 |
| has_source=false | MiddlewareNode 禁用源码懒加载（不显示"查看源码"按钮） |
| fetchSource 失败 | 源码折叠块内显示"⚠ 源码加载失败：{错误}"，不阻断其他节点 |
| agent 名不在 AGENT_LABELS | 徽章显示机器名（agentLabel 回退） |
| middleware 无 hook 值（null） | 归入"未挂载"列（泳道图最右侧追加一列，或在表头标注） |
| prompt body 为空 | Prompt Tab 该 agent 段显示"（无 prompt）" |
| skills 为空数组 | Skills Tab 该 agent 段不显示 |
