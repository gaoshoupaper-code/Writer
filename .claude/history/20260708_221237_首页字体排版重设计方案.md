# 首页字体排版重设计方案

## 关联需求

见 `20260708_215725_首页字体排版重设计.md`。七项决策（D1~D7）已冻结，本设计在其约束内推演 HOW。

## 技术现状（已核对）

| 维度 | 现状 |
|------|------|
| 框架 | Astro 7.0.6，`defineConfig({})` 空配置，无 vite 插件先例 |
| 全局样式 | 无 Layout 组件、无全局 CSS；`:root` + `:global(body)` 在 index.astro / download.astro 各复制一份 |
| 字体 | Google Fonts `<link>` 加载 Noto Serif SC（400/600/900），无本地字体文件 |
| public/ | 无 fonts 目录 |
| 依赖 | 仅 astro + zod；cn-font-split 为新增构建依赖 |

## 架构方向（待确认主路径）

**推荐主路径：构建期子集化 + 共享 base.css**

```
website/
├── public/fonts/              ← 新增：本地字体文件
│   └── subset/                ← cn-font-split 产物（多分片 woff2 + index.css）
├── scripts/                   ← 新增：子集化脚本
│   └── split-font.mjs         ← 开发期手动跑一次，产物提交 git（非每次构建）
├── src/
│   ├── styles/
│   │   └── base.css           ← 新增：token + 排版 scale + :global(body) 基底
│   └── pages/
│       ├── index.astro        ← 改：删内联基底、import base.css、套用 scale
│       └── download.astro     ← 同上
└── astro.config.mjs           ← 不动
```

**核心设计原则：**
1. 排版 scale 全部用 CSS 变量定义，页面内 var() 引用
2. base.css 用 `@import` 引入字体 CSS（或页面 <head> 注入）
3. 字体子集化产物提交 git，不纳入每次 build（避免 CN 字体反复合并）
4. 渐进迁移：保留现有 class 名，只改其内部 font-* 属性指向 var()

## 排版 Token 设计（基于 D9 模数推演）

### 字号 scale（base=16, ratio=1.2, Major Third）

纯中文站，全 px 化（不引入 rem 复杂度，Astro 静态站无需 rem 缩放能力）。

| 语义 token | 像素值 | 用途 | 现状对照 |
|-----------|--------|------|---------|
| `--fs-meta` | 12px | 版权、rail 序号 | 原 12px ✓ |
| `--fs-kicker` | 13px | hero kicker、版本号 | 原 13px ✓ |
| `--fs-small` | 13px | 辅助说明（≤13 回退无衬线，见 D6） | 原 14.5/15 混用 |
| `--fs-body` | 16px | 卡片描述、正文 p/li | 原 14.5/15/16/17 混乱 |
| `--fs-body-lg` | 17px | hero 副标题、步骤说明 | 原 17px |
| `--fs-h5` | 19px | 卡片标题（非主卡） | 原 clamp(20,2vw,25) |
| `--fs-h4` | 23px | 下载卡 label、closing line | 原 18/20/30 混乱 |
| `--fs-h3` | 28px | section title（下载页） | 原 clamp(28,3.8vw,44) |
| `--fs-h2` | 33px | section title（首页） | 原 clamp(30,4.2vw,48) |
| `--fs-h1` | 40px | hero 标题最小值 | 原 clamp 下限 40 |
| `--fs-display` | clamp(48px, 7vw, 69px) | hero 标题 | 原 clamp(40,6.4vw,78) |
| `--fs-brand` | 22px | 品牌名 | 原 21px |

**关键变更**：废除原 `14.5/15/16/17` 四档含糊，正文统一 16，副标题 17，辅助一律 ≤13。标题档差从"78→48→32"的断裂改为"69→48→40→33→28→23"的平滑等比。

### 字重体系（废除 900 滥用）

| token | 值 | 用途 |
|-------|-----|------|
| `--fw-regular` | 400 | 正文 |
| `--fw-medium` | 500 | nav、CTA、强调正文 |
| `--fw-semibold` | 600 | 标题、卡片标题、品牌名 |
| ~~`--fw-black`~~ | ~~900~~ | **废除** |

**关键变更**：所有标题从 `900` 降档到 `600`。中文衬线 900 视觉上接近黑体，发死；600 兼顾力度与笔锋。

### 字距体系（核心修复：废除负字距）

| token | 值 | 用途 |
|-------|-----|------|
| `--tracking-cn-tight` | 0 | 中文大标题（≥48px），零字距 |
| `--tracking-cn` | 0.02em | 中文标题（28~40px），微张 |
| `--tracking-cn-body` | 0.04em | 中文正文（≤23px），松一点助读 |
| `--tracking-label` | 0.12em | 全大写 label（rail-label、section-num），大写才用大字距 |

**关键修复**：原 `letter-spacing: -0.01em`（负字距压方块字）→ 改为 `0` 或正字距。这是"不笨"的核心。

### 行高体系（5 值散落 → 2 档收敛）

| token | 值 | 用途 |
|-------|-----|------|
| `--lh-tight` | 1.15 | 标题（display/h1~h3） |
| `--lh-body` | 1.75 | 正文（body/段落/列表），中文衬线需更松 |

**关键变更**：标题 `1.06/1.08` 过紧（中文方块字上下贴边）→ `1.15`；正文 `1.6/1.65/1.7` 散落 → 统一 `1.75`。

### 字体家族

| token | 值 | 用途 |
|-------|-----|------|
| `--font-serif` | `"Noto Serif SC", "Songti SC", "Source Han Serif SC", serif` | ≥14px 全部（标题+正文） |
| `--font-sans` | `system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif` | ≤13px meta/kicker/label（D6 回退） |
| `--font-mono` | `ui-monospace, "SF Mono", "Cascadia Code", monospace` | 版本号、尺寸数字（tabular-nums 配套） |

**关键变更**：正文从 system-ui → Noto Serif SC（D1）；保留 system-ui 栈作为小字回退（D6）。fallback 链简化（删除"STSong/SimSun"等冗余回退，Noto 失败直接退系统衬线即可）。

### 锁定的关键数值

| 决策 | 值 |
|------|-----|
| D11 | hero 标题 `--fs-display: clamp(48px, 7vw, 69px)` |
| D12 | 正文 `--fs-body: 16px`，`--lh-body: 1.75` |

| `.section-title` (下载页) | serif 900, clamp(28,3.8vw,44) | `font: 600 var(--fs-h3)/var(--lh-tight) var(--font-serif); letter-spacing: var(--tracking-cn)` |
| `.section-lead` | 16px sans | `font: 400 var(--fs-body)/var(--lh-body) var(--font-serif); letter-spacing: var(--tracking-cn-body)` |
| `.card__title` | serif 600, clamp(20,2vw,25) | `font: 600 var(--fs-h5)/var(--lh-tight) var(--font-serif); letter-spacing: var(--tracking-cn)` |
| `.card--lead .card__title` | clamp(24,2.6vw,32) | `font-size: var(--fs-h4)` （23px，比原 32 收敛） |
| `.card__desc` | 15px sans | `font: 400 var(--fs-body)/var(--lh-body) var(--font-serif)` |
| `.card__body p/li` | 14.5px sans, lh1.7 | `font-size: var(--fs-body); line-height: var(--lh-body); font-family: var(--font-serif)` |
| `.closing__line` | serif 600, clamp(22,2.6vw,30) | `font: 600 var(--fs-h4)/var(--lh-tight) var(--font-serif)` |
| `.brand__name` | serif 900, 21px, ls0.01em | `font: 600 var(--fs-brand)/var(--lh-tight) var(--font-serif)` |
| `.kicker` | 13px sans, ls0.04em | `font-family: var(--font-sans); font-size: var(--fs-kicker); letter-spacing: var(--tracking-cn-body)` |
| `.rail__label` | 12px sans uppercase, ls0.12em | `font-family: var(--font-sans); font-size: var(--fs-meta); letter-spacing: var(--tracking-label)`（保持 uppercase） |
| `.pipeline__name` | serif 600, 17px | `font: 600 var(--fs-body-lg)/var(--lh-tight) var(--font-serif)` |
| `.pipeline__desc` | 13px sans | `font-family: var(--font-sans); font-size: var(--fs-small)` |
| `.btn` | 15px sans 600 | `font: 600 var(--fs-body)/1 var(--font-sans)`（按钮用无衬线，保清晰锐利） |
| `.topbar__nav a` | 15px sans | `font-family: var(--font-sans); font-size: var(--fs-body)` |
| `.foot__copy/.foot__nav a` | 13/14px sans | `font-family: var(--font-sans); font-size: var(--fs-small)` |

**按钮/导航/页脚保留无衬线**：交互元素的字体不随正文走衬线——CTA 按钮、导航链接需锐利清晰，衬线在小按钮里会显软。这是 D6 的延伸判断（交互小字 = 无衬线）。
