# 记忆系统改造设计（P1-P3）

> 需求基准：`.claude/md/20260714_100000_记忆系统改造落地.md`（11 个冻结决策）

## 1. 架构快照

### 1.1 三端分层（决策已敲定）

| 层 | 归属 | 职责 | 可进化性 |
|----|------|------|---------|
| **contracts** | `contracts/runtime_context.py` + 新增 `contracts/memory.py` | RuntimeContext 扩展 + 记忆数据契约（schema 定义类型、trace 字段） | 固定 |
| **executor 记忆基础设施** | `executor/app/platform/memory/` | MemoryBackend 抽象（固定原语：retrieve/add_episode/ingest_storybuilding）、Graphiti 客户端单例、FalkorDB 连接、异步入图管道 | 固定 |
| **harness 记忆要素** | `evolution/harnesses/repo/{middleware,tools,prompts}/` | memory_recall_middleware（查询构造+证据包组装）、narrative_schema、StoryCalendar、抽取 prompt | 可进化 |

### 1.2 固定/可进化接口边界（断层 1 已解）

```
executor/platform/memory/MemoryBackend（固定原语）
  ├─ retrieve(query, filters, budget) → EvidencePacket
  │    └─ 内部封装 Graphiti search + BM25 + Vector + RRF + One-Hop 扩展
  ├─ add_episode(name, body, ref_time, group_id, schema) → None
  └─ ingest_storybuilding(workspace_path, group_id, schema) → None

harness/middleware/memory_recall_middleware.py（可进化编排）
  ├─ _build_query(detail_outline, chapter_num) → str      # 查询条件构造
  ├─ before_model():                                      # 编排
  │     query = self._build_query(...)
  │     packet = self.backend.retrieve(query, filters, budget=12000)  # 调固定原语
  │     return {"messages": [HumanMessage(packet.formatted)]}         # 证据包组装格式
```

**原则**：四阶段的"执行"（Graphiti API、向量/BM25 计算、图扩展）固定在 MemoryBackend；"编排策略"（查询怎么构造、预算怎么分、证据包怎么排版）可进化在 middleware。Graphiti 版本升级只影响固定层，不冲击 harness。

### 1.3 入图触发点（断层 3 已解）

| 事件 | 触发点 | 落点 | 现有对照 |
|------|--------|------|---------|
| storybuilding 完成 → 蓝图入图 | `_on_storybuilding_done`（events.py:325） | 追加 `_on_storybuilding_ingest()` 并行副作用，与 `generate_storyline_graph` 同构 | 复用现有事件分发 |
| 章节写完 → Causal 入图 | `_on_writing_chapter_done`（events.py:333） | 追加入图逻辑，`asyncio.to_thread` 异步 | 复用现有事件分发 |

### 1.4 失败语义（断层 2 已解）

| 时机 | 失败处理 | 架构依据 |
|------|---------|---------|
| **memory_recall（before_model，写前同步检索）** | 立即中断当前写作 | middleware 在 LLM 调用前执行，返回前抛错即可中断 |
| **入图（写后异步）** | 标记作品"图谱不可用"，下次 memory_recall 检测到标记则报错中断 | SSE 流不等入图；失败用 workspace 级 flag 传播 |

入图失败传播机制：workspace 级 flag（如 `workspace/.memory_state` 或 FalkorDB 健康检查），memory_recall 启动时先查 flag，标记为不可用则直接报错。

## 2. 数据与状态

### 2.1 narrative_schema（可进化，harness 包内）

**位置**：`evolution/harnesses/repo/tools/narrative_schema.py`
**定义形式**：Pydantic BaseModel 子类（Graphiti `add_episode(entity_types=dict[str,BaseModel])`）
**约束**：字段名不能与 EntityNode 冲突（uuid/name/group_id/labels/created_at/summary/name_embedding 等保留）

```python
# harnesses/repo/tools/narrative_schema.py（可进化，evolution agent 能改）
from pydantic import BaseModel, Field

class CharacterEntity(BaseModel):
    """角色节点。"""
    aliases: list[str] = Field(default=[], description="别名/称呼列表")
    role_type: str = Field(description="主角/配角/反派等")

class LocationEntity(BaseModel):
    """地点节点。"""
    description: str = Field(default="", description="地点描述")

class WorldFactEntity(BaseModel):
    """世界规则/设定节点。"""
    category: str = Field(description="规则类别")

class ThreadEntity(BaseModel):
    """故事线节点。"""
    thread_type: str = Field(description="主线/支线")
    status: str = Field(description="活跃/完结")

class StoryNodeEntity(BaseModel):
    """叙事事件节点（来自 storyline E0XX）。"""
    event_type: str = Field(description="冲突/危机/反转/悬念/揭露/胜利/交汇")
    event_group: str = Field(description="G00开端/G01发展/G02终局")
    story_time: str = Field(description="故事内时间，如 2087年2月15日")
    plot_summary: str = Field(description="事件简述")

# 对应 edge_types 同理定义（带双时间戳语义，但 Graphiti 已有 valid_at/invalid_at）
```

**P1 schema 范围**：Character + Location + WorldFact + Thread + StoryNode（决策3 扩展）。Promise/伏笔状态机留 P2。

### 2.2 Graphiti schema 验证约束

- Graphiti `validate_entity_types` 检查自定义类型字段名不与 EntityNode 冲突（entity_types_utils.py）
- 双时间戳由 Graphiti 原生支持（valid_at/invalid_at），edge 不需自定义时间字段
- StoryCalendar 把 story_time（虚构历法）转成 reference_time（datetime）后传 add_episode

### 2.3 MemoryBackend 生命周期（决策已敲定）

**模式**：进程内单例，与 trace_recorder 完全同构。
**隔离**：Graphiti group_id 参数做作品隔离。
**group_id 构成**：`f"{owner_id}:{workspace_name}"`（owner_id 来自 RuntimeContext，workspace_name 从 workspace_path 取末段）。

## 3. 接口契约

### 3.1 MemoryBackend（固定原语，executor 端）

**位置**：`executor/app/platform/memory/backend.py`
**生命周期**：进程单例，RuntimeContext 注入。

```python
class MemoryBackend:
    """记忆系统固定基础设施。封装 Graphiti 调用，对 harness 隐藏图库细节。"""

    def __init__(self, graphiti_client: Graphiti, schema: dict):
        """schema 从 harness 包读取（可进化），client 执行端创建（固定）。"""
        self._client = graphiti_client
        self._schema = schema

    async def retrieve(
        self,
        query: str,
        group_id: str,
        causal_cutoff_chapter: int | None = None,
        budget_chars: int = 12000,
        num_results: int = 10,
    ) -> EvidencePacket:
        """四阶段检索的固定执行（middleware 调用）。
        
        内部：Causal Restriction → Graphiti hybrid search → One-Hop expansion → Bounded assembly
        返回：有界证据包（字符数 ≤ budget_chars）
        """

    async def add_episode(
        self,
        name: str,
        episode_body: str,
        reference_time: datetime,
        group_id: str,
    ) -> None:
        """章节正文入图（Causal Publish Flow）。用 schema 引导抽取。"""

    async def ingest_storybuilding(
        self,
        workspace_path: Path,
        group_id: str,
        calendar: StoryCalendar,
    ) -> None:
        """storybuilding 蓝图层结构化入图。
        
        读 storyline/*.md + character/*.md + worldview.md，
        按固定结构解析（非 LLM 抽取），建 Thread/StoryNode/Character/Location 节点+边。
        """

    async def health_check(self) -> bool:
        """FalkorDB 连通性检查（memory_recall 启动时调，决策10 失败语义）。"""


@dataclass
class EvidencePacket:
    """检索返回的证据包。formatted 供 middleware 注入 prompt。"""
    nodes: list[dict]      # 命中的图节点（Character/Thread/StoryNode 等）
    edges: list[dict]      # 命中的关系边
    formatted: str         # 已排版好的文本（≤ budget_chars），直接注入 HumanMessage
    token_estimate: int    # 估算 token 数（trace 埋点用，P3）
    query_used: str        # 实际查询（trace 埋点用，P3）
```

### 3.2 memory_recall_middleware（可进化编排，harness 包内）

**位置**：`evolution/harnesses/repo/middleware/memory_recall_middleware.py`

```python
class MemoryRecallMiddleware(AgentMiddleware):
    """写作前从图谱召回记忆，注入 prompt。替代 ContextAssembler 对 writing 的全量注入。"""

    def __init__(self, backend: MemoryBackend, group_id: str, budget: int = 12000):
        self._backend = backend
        self._group_id = group_id          # 实例化时注入（assemble 时从 ctx 算出）
        self._budget = budget              # 可进化参数

    async def abefore_model(self, state, runtime) -> dict | None:
        # 1. 决策10 失败语义：先健康检查，不可用则抛错中断
        if not await self._backend.health_check():
            raise MemoryUnavailableError("图谱不可用，按策略中断写作")
        
        # 2. 从 task description 提取章节号（复用 events._extract_chapter_index 逻辑）
        task = _extract_task(state["messages"])
        chapter_num = _extract_chapter_index(task)
        
        # 3. 构造查询（可进化：查询条件构造逻辑）
        query = self._build_query(task, chapter_num)
        
        # 4. 调固定原语检索
        packet = await self._backend.retrieve(
            query=query,
            group_id=self._group_id,
            causal_cutoff_chapter=chapter_num,
            budget_chars=self._budget,
        )
        
        # 5. 组装注入（可进化：证据包排版格式）
        return {"messages": [HumanMessage(content=packet.formatted)]}

    def _build_query(self, task: str, chapter_num: int | None) -> str:
        """可进化：从 task description（含本章事件/出场人物）构造检索查询。"""
        ...
```

**与 ContextAssemblerMiddleware 的关系**（决策4 落地）：
- writing 子代理：**只挂 memory_recall_middleware**（不挂 ContextAssembler）

### 3.5 health_check（决策已敲定）

**策略**：进程级 TTL 缓存 30 秒。
- MemoryBackend 内部维护 `_health_cache: tuple[bool, float]`（状态 + 时间戳）
- `health_check()` 查缓存：30 秒内的缓存直接返回；过期则实时查 FalkorDB（一次 PING）
- memory_recall 的 abefore_model 调 health_check：健康继续，不健康抛 MemoryUnavailableError

30 秒窗口的取舍：FalkorDB 挂是低频事件，30 秒内"过时健康"窗口可接受；避免每章写作的网络往返。

### 3.6 入图失败传播（决策已敲定）

**机制**：workspace 级隐藏文件 flag。
- 入图失败 → 在 workspace 下写 `.memory_unhealthy`（内容：失败原因 + 时间戳）
- memory_recall 的 abefore_model 启动时检查该文件：存在则抛 MemoryUnavailableError 中断写作
- 入图成功 → 删除该文件（恢复健康）
- 文件存在与 FalkorDB 是否存活解耦——某章抽取失败也能标记，不依赖图库还活着
