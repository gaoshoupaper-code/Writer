### 数据流转（历史 tab → workbench）

```
HistoryTab 点 session
  ↓ navigate('/evolve?tab=workbench&session=xxx')

  ↓ setTab('workbench') + 透传 initialSessionId 给 WorkbenchTab

中栏加载对话 + 右栏加载进化点
```

## 数据与状态

### URL State 契约（桌面端进化页）

```
/evolve                                → 默认 tab=workbench，无 session 选中
/evolve?tab=workbench                  → 工作台（无选中 session，中栏显示启动入口）
/evolve?tab=workbench&session=xxx      → 工作台 + 选中 session xxx
/evolve?tab=history                    → 历史 tab（列表）
/evolve?tab=blueprint                  → 蓝图 tab
```

- URL 是 single source of truth：`tab` + `session` 都从 `useSearchParams` 读，`setTab` 同步写回 URL（`setSearchParams`）。
- 非法值兜底：`tab` 不在 `{workbench, history, blueprint}` → 回退 workbench；`session` 不在列表 → workbench 中栏显示启动入口（不报错）。

### 记忆要素认知模型（蓝图 ③ 段九要素）

```
包内要素（harnesses/current/）：
  prompts / middleware / tools / subagents / skills / assemble
  +
  memory（横切跨 prompts/middleware/tools 三类的协同链）
    ↓ 物理散落但语义连贯：
    抽取(extract): prompts/memory_extraction_guide.md
    存储(store):   tools/narrative_schema.py
    检索(retrieve): tools/query_builder.py + join_rules.py + packet_formatter.py
    回填(recall):  middleware/memory_recall_middleware.py

框架层要素（不在包目录）：
  assemble 续（create_deep_agent）/ State
```

**memory 独立一类的理由**：物理散在 3 个目录但语义是一条协同链（抽取→存储→检索→回填），把它当一等公民能让 Agent 理解"改一个检索要素会影响整条链"，而不是孤立看某个文件。

### Agent 工作流（蓝图 ⑥ 段五阶段）

```
① 理解  → 读评估报告（findings/分数）+ 读 trace（关键节点）+ 读反思库
           产出：脑子里有问题清单 + 证据 id
② 规划  → list_elements + read_source 探查要素 + write_design_doc 写方案
           产出：design_doc.md（每条改动指向要素 + 引用证据）
③ 执行  → write_*（新建）/ edit_source（修改）落地每个改动
           产出：源码改动落地
④ 验证  → validate_changes（py_compile + import 检查，最多 2 次）
           产出：校验通过 / 失败清单
⑤ 记录  → write_change_log（applied + summary）
           产出：change_log.md（FlowGuard 强制 design_doc 在前）
```

**记忆要素改动的特殊约束**（固化进 ③ 段 memory 类描述）：
- 改前必须 `read_source` 读懂现有逻辑
- 改 `query_builder/join_rules/packet_formatter`（检索三要素）须保持 NWM 论文 §A.1 四阶段结构 + 因果锚点（source_chapter≤N-1）不变
- 改 `narrative_schema` 不得破坏 8 类 typed records 的字段契约（executor 端 store/extractor 依赖）
- 改 `memory_recall_middleware` 保持降级语义（失败 return None，ContextAssembler 兜底）
- 改 `memory_extraction_guide` 不得删除 8 类 record 的抽取指令

### 桌面端组件接口（新增/改动）

**`EvolvePage`（pages/evolve.tsx）改动**：
```typescript
type Tab = "workbench" | "history" | "blueprint";  // +history

export default function EvolvePage() {
  const [searchParams, setSearchParams] = useSearchParams();
  const tab = (searchParams.get("tab") as Tab) ?? "workbench";
  const sessionId = searchParams.get("session") ?? null;

  const switchTab = (t: Tab) => setSearchParams(prev => { prev.set("tab", t); return prev; });
  const selectFromHistory = (id: string) => setSearchParams(prev => {
    prev.set("tab", "workbench");
    prev.set("session", id);
    return prev;
  });

  return (
    <>
      <nav>...3 个 tab 按钮（workbench/history/blueprint）...</nav>
      {tab === "workbench" && <WorkbenchTab initialSessionId={sessionId} onNoSession={() => switchTab("history")} />}
      {tab === "history"   && <HistoryTab onSelect={selectFromHistory} />}
      {tab === "blueprint" && <BlueprintTab />}
    </>
  );
}
```

async def _handle_recursion_error(ctx: EvolveContext, round_name: str) -> None:
    """GraphRecursionError 兜底（DD7）：标 failed + recorder 收尾 + emit_log。
    各 round 的 except GraphRecursionError 分支调用，然后自己 return 状态 dict。"""
