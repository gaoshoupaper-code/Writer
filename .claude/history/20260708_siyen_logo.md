# 思衍（Siyen）Logo 升级需求

## 核心诉求（已确认）

把原图（深色背景 + 中心金色发光五角星 + 外围多层彩虹渐变同心圆环）**裁成圆形**，去掉方形画布四角的深色背景，**完整保留圆环 + 中心星星**，作为"思衍（siyen）"产品的 logo。

## 已确认的关键决策

| 决策点 | 结论 |
|---|---|
| 裁切范围 | 裁成圆形，**彩虹同心环 + 中心星星全部保留** |
| 品牌寓意 | 不在意五角星与"思衍"的寓意连接，纯粹喜欢这张图 |
| 交付格式 | **SVG 矢量 logo 代码**（+ HTML 预览页） |
| 圆边界 | **最外层彩虹环**为边界，紧凑无多余边距 |
| 圆内背景 | **保留深色背景**（最还原原图的发光效果） |
| 文字组合 | **只要图形 logo，不要文字**（最通用，可独立用作图标） |
| 小尺寸变体 | **要 favicon 简化版**（去掉细环，保留星 + 主环） |
| 单色版 | **要单色轮廓版**（纯黑 / 纯白，用于印章/单色印刷/反色场景） |
| 配色精度 | **允许微调升级**（清理杂色、优化渐变层次、精致化星星，非像素级复刻） |

## 交付清单（需求冻结）

1. **完整彩色版 SVG** — logo 主体，圆边界=最外层彩虹环，深色背景，彩虹环 + 发光金星
2. **favicon 简化版 SVG** — 小尺寸优化，去掉细环，保留星星 + 主轮廓环
3. **单色轮廓版 SVG** — 纯黑 / 纯白轮廓，用于单色场景
4. **HTML 预览页** — 在同一页面展示三个版本，便于对照查看
