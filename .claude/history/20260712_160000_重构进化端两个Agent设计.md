# 设计：重构进化端两个 Agent

## 架构快照

### 改动总览

两个 Agent 各自重构，一减一增：

| | 评估 Agent | 进化 Agent |
|---|---|---|
| **改动性质** | 外科手术（纯减法） | 器官移植（重构） |
| **核心变化** | 删 surface 工具组 + 清理 prompt | driver+subagents 三体 → 单体 + 全要素认知 + 15 工具 |
| **改动文件数** | ~4 个 | ~20+ 个（新建 agent/ 包 + 删 driver/subagents） |

## 已确认设计决策（14 条）

### S1：目录结构 = 新建 evolve/agent/ 包
废弃 driver/ 和 subagents/，新建 evolve/agent/ 包（agent.py + prompt.py + tools/ + middleware/）。ctx.py/api.py/docs.py 原地保留。

### S2：工具模块 = 按功能类型分 3 模块
inspect.py（4 探查）/ writers.py（5 写 + 1 edit）/ flow.py（5 流程）。

### S3：编排 = prompt 软引导 + 轻量产出约束 middleware
system prompt 描述建议工作流程（不强制顺序）+ FlowGuardMiddleware 做产出依赖约束。

### S4：FlowGuardMiddleware = 2 条产出依赖
1. 无 design_doc 拦 change_log（wrap_tool_call）。
2. 结束前检查产出齐（after_agent nudge，最多 3 次）。

### S5：专用写工具 = write 全量 + edit 增量
5 个 write_*（仅新建，backend.write）+ 1 个 edit_source（修改，backend.edit）。工具总数 15。

### S6：全景 prompt = 7 段完整结构
①角色 ②能力边界 ③要素全景 ④运转机理 ⑤State/Middleware 约束 ⑥工作流程建议 ⑦工具说明。

### S7：NoFilesystemToolsMiddleware 提共享位置
移到 app/common/middleware/no_fs.py，eval_agent re-export 兼容。

### S8：inspect_state_schema = 硬编码文档
返回 State 字段清单（messages/todos/files/memory_contents/goal 等），每个标明来源 + 承载什么 + 能否经 Middleware 操作。

### S9：validate_changes = 纯源码校验
py_compile 全包 + import 新改动模块。废弃 config 校验。

### S10：emit_step 删 phase 参数
单体 Agent 无阶段概念，所有 emit_step 调用去掉 phase=。

### S11：构建函数 = build_evolve_agent / agent_name = "evolve-agent"
与 build_eval_agent / "eval-agent" 对称。

### FlowGuardMiddleware 状态

```python
class FlowGuardMiddleware(AgentMiddleware):
    _nudge_count: int = 0     # after_agent nudge 计数
    # 无 phase 状态（不像 PhaseGuard 维护当前阶段）
```

### 产出依赖约束逻辑

```
write_change_log 调用:
  if ctx.design_doc_path 为空:
    → 返回拦截 ToolMessage "先产出 design_doc"

after_agent:
  if design_doc_path 和 change_log_path 都齐:
    → 放行结束
  elif nudge_count < 3:
    → nudge_count++, 注入"请继续产出"
  else:
    → 放行结束
```

## 接口契约

### build_evolve_agent(ctx) → CompiledStateGraph

```python
def build_evolve_agent(ctx: EvolveContext):
    set_tool_context(ctx)
    model = build_agent_model(temperature=0.2)

    backend = FilesystemBackend(
        root_dir=str(settings.harness_work_dir_path),
        virtual_mode=True,
    )
    tools = make_evolve_tools(backend=backend)  # 15 工具

    system_prompt = evolve_system_prompt(
        session_id=ctx.session_id,
        trace_id=ctx.trace_id,
        eval_summary=_format_eval_summary(ctx),
        reflections_summary=_format_reflections(ctx),
    )

    middleware_list = [
        NoFilesystemToolsMiddleware(),
        FlowGuardMiddleware(),
    ]
    trace_mw = TraceMiddleware(...) if ctx.recorder and ctx.trace_id_self else None
    if trace_mw:
        middleware_list.append(trace_mw)

    return create_deep_agent(
        model=model,
        tools=tools,
        system_prompt=system_prompt,
        middleware=middleware_list,
        subagents=None,
        backend=backend,
        checkpointer=None,
    )
```

### 工具清单（15 个）

**inspect.py（4 探查，只读，给认知）：**

| 工具 | 签名 | 内部实现 |
|------|------|----------|
| list_elements | `() → str` | rglob harnesses/current/，按目录归类列出八要素文件清单 |
| read_source | `(path: str) → str` | backend.read(path)，读任意要素源码 |
| inspect_state_schema | `() → str` | 返回硬编码 State 字段文档（S8） |
| read_assemble | `() → str` | backend.read("/__init__.py")，读 assemble 源码 |

**writers.py（5 写 + 1 edit，受控写，封装 backend）：**

| 工具 | 签名 | 内部实现 |
|------|------|----------|
| write_prompt | `(name: str, content: str) → str` | backend.write(f"/prompts/{name}.md", content)，仅新建 |
| write_middleware | `(name: str, code: str) → str` | backend.write(f"/middleware/{name}.py", code)，仅新建 |
| write_tool | `(name: str, code: str) → str` | backend.write(f"/tools/{name}.py", code)，仅新建 |
| write_skill | `(path: str, content: str) → str` | backend.write(f"/skills/{path}", content)，仅新建 |
| write_subagent | `(name: str, code: str) → str` | backend.write(f"/subagents/{name}.py", code)，仅新建 |
| edit_source | `(path: str, old_string: str, new_string: str) → str` | backend.edit(path, old_string, new_string)，修改已有 |

**flow.py（5 流程，从 plan/execute 归并）：**

| 工具 | 签名 | 说明 |
|------|------|------|
| read_eval_report | `() → str` | 从 ctx.eval_snapshot 读评估报告（原 plan 版搬来） |
| read_trace | `(trace_id: str) → str` | 读 trace 摘要（原 plan 版搬来，去 phase） |
| write_design_doc | `(changes_json: str, rationale: str) → str` | 产 design_doc.md（原 plan 版搬来，去 phase） |
| validate_changes | `() → str` | 纯源码校验（S9，重写） |
| write_change_log | `(applied_json: str, summary: str) → str` | 产 change_log.md（原 execute 版搬来，去 phase） |

**所有写工具共享**：FilesystemBackend 实例由 make_evolve_tools(backend=) 注入。

**所有工具的 name sanitize**：每个写工具内部对 name/path 参数做 sanitize（防路径穿越），backend 的 virtual_mode 再做一层拦截。

## 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 全景 prompt 过长（3000+字）| 占用 context window | 7 段结构已尽量精炼；探查工具补动态信息，prompt 只放抽象知识 |
| 单体 Agent 不收敛（反复改源码不收尾）| 进化流程跑不完 | FlowGuard after_agent nudge + 框架默认步数上限兜底 |
| Agent 写的 middleware 源码有运行时错误 | agent 装配失败 | validate_changes 的 import 检查 + 发版前人工 review |
| backend.write 拒绝覆盖导致 Agent 困惑 | Agent 不知道新建 vs edit 的区别 | write_* 报错信息明确提示"文件已存在，请用 edit_source 修改"；prompt 第 7 段说明 |
| eval_agent re-export 链断裂 | eval_agent import 失败 | Phase 2 优先做，先验证再继续 |
