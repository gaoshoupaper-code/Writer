# 进化端数据集展示功能 — 技术设计

## 架构快照

**技术栈对齐**：前端为主 + 后端一处微调。
- 前端：React 19 + react-router-dom 7（HashRouter）+ Tailwind v4 + Radix UI（Tabs/Sheet/Dialog 已引入）
- API 层：复用 `evolution/desktop/src/lib/api.ts` 的 `evoJson`/`evoFetch`（Tauri Rust 中继），新增 dataset/promote 两组封装
- UI 模式：对齐现有 `tests.tsx`（`useEffect` + `setInterval` 轮询 + `data-table` + sonner toast + action-link 按钮）
- 后端：全部 API 已就绪，仅 `_row_to_summary` 补一个 `judge_scores` 字段（SD1）

**新增文件**：
```
evolution/desktop/src/
  ├─ pages/dataset.tsx                    ← 数据集主页面（Tab 容器）
  └─ components/dataset/
      ├─ GoldenTab.tsx
      ├─ GrowingTab.tsx
      ├─ ReviewTab.tsx
      └─ CaseDetailSheet.tsx             ← 共用详情侧滑（golden+growing）
```

**改动文件**：
```
evolution/desktop/src/
  ├─ App.tsx                              ← 加 /dataset 路由
  ├─ components/Shell.tsx                 ← NAV_ITEMS 加「数据集」项
  └─ lib/api.ts                           ← 加 dataset/promote 封装
evolution/app/promote/api.py              ← _row_to_summary 补 judge_scores（SD1）
```

### 设计决策 SD1：后端 summary 补 judge_scores 字段 ✅
- 改动：`evolution/app/promote/api.py` 的 `_row_to_summary` 加 `judge_scores` 字段（JSON 解析，与 `_row_to_detail` 同逻辑）
- 理由：该字段已存在于 `promote_tasks` 表，summary 只是没取出来。一行改动，前端避免 N+1 请求
- 这是对需求"后端已就绪"的合理微调——字段已存储，接口契约不破坏（新增字段是向后兼容的）

### 设计决策 SD2：主页面做 Tab 容器，每 Tab 独立子组件 ✅
- `dataset.tsx`：用 Radix `Tabs`（`tabs.tsx` 现成）渲染 Tab 栏 + TabsContent 条件渲染子组件
- 三个子组件各自管理数据获取、刷新策略、状态
- 目录：`evolution/desktop/src/components/dataset/` 下放子组件
- 职责分离：待标注要轮询（5s），golden 几乎静态，growing 偶尔变

### 设计决策 SD3：case 详情 + accept 表单用 Sheet 侧滑面板 ✅
- 用 `sheet.tsx`（基于 `@radix-ui/react-dialog`，右侧滑入，max-width 560px，可滚动）
- **case 详情**（demand.md + reference.md + 元数据）：点行打开 Sheet
- **accept 表单**（单选归入/新建 + 字段）：点 accept 打开 Sheet
- 统一用 Sheet，不新建 dialog 组件，减少样式碎片

### 设计决策 SD4：CaseDetailSheet 共用，onPromote prop 控制升级按钮 ✅
- Golden + Growing 共用一个 `CaseDetailSheet` 组件
- props: `case: DatasetCase`、`onClose`、`onPromote?`（growing 时传入升级回调，golden 时不传）
- 内部根据 `onPromote` 是否存在决定是否渲染升级按钮

### 设计决策 SD6：Tab 用 Radix Tabs，接受切走卸载 ✅
- 直接用 `tabs.tsx`（`Tabs`/`TabsList`/`TabsTrigger`/`TabsContent`）
- 接受 Radix 默认行为：切走 Tab 时 TabsContent 卸载，回来重新挂载+请求
- ReviewTab 切走时 5s 轮询自动停止（setInterval 被 cleanup），不看时不浪费请求
- 理由：开发者自用，切回重新请求 1 秒可接受，不值得为保活增加复杂度

### 设计决策 SD7：accept 表单交互 ✅
- reject：一键操作，confirm 确认后直接提交（对齐 tests.tsx 的 deleteTest 用 `confirm()`）
- accept：点按钮打开 Sheet 侧滑表单：
  - 单选：○ 归入已有 case（下拉选 growing case） ○ 新建 case（title 输入框 + demand_md 文本域）
  - reference_output：可选文本域（placeholder 提示"留空自动从 trace 提取编辑终稿"）
  - 提交按钮，成功后 toast + 关闭 Sheet + 刷新列表

### 设计决策 SD5：judge 分数徽章取 content_overall ✅
- `judge_scores.content_overall` 是 0~1 的浮点数，是 promote verdict 的判定依据
- 徽章显示逻辑：
  - `>= 0.8`（auto_promote）→ 绿色徽章，显示分数（如 `0.82`）
  - `0.4~0.8`（needs_human）→ 黄色徽章，显示分数
  - `< 0.4`（auto_reject）→ 红色徽章，显示分数
  - `null`（未 judge / filter 淘汰）→ 灰色「未评」
- 完整 judge_scores（content_scores/subagent_scores/badcase）在 Modal 详情里展开

## 接口契约（lib/api.ts 新增封装）

### 数据集（dataset）— 4 个函数

```typescript
// 类型
interface DatasetCase {
  case_id: string;
  title: string;
  layer: "golden" | "growing";
  source_trace_id: string | null;
  demand_revision: string | null;
  promoted_at: string | null;
  created_by: string;
  has_reference: boolean;
}

interface GoldenRevision {
  revision: string;
  locked: boolean;
  intact: boolean;
  case_count: number;
  cases: string[];
}

// 函数（均走 evoJson，自动加 /evolution-api 前缀）
getDatasetCases(layer?: "golden" | "growing")
  → GET /api/dataset/cases?layer=...
  → { cases: DatasetCase[]; total: number }

getGoldenRevision()
  → GET /api/dataset/golden-revision
  → GoldenRevision

promoteCaseToGolden(caseId: string)
  → POST /api/dataset/cases/{caseId}/promote
  → { case_id, layer, demand_revision, golden_case_count }
```

### 标注队列（promote）— 3 个函数

```typescript
// 类型
interface PromoteTask {
  task_id: string;
  trace_id: string;
  owner_user_id: string | null;
  status: string;                    // pending|judging|needs_confirm|rejected|promoted
  judge_verdict: string | null;      // auto_promote|needs_human|auto_reject
  judge_scores: {                    // SD1 后列表也带（之前只有 detail 有）
    content_overall: number;
    content_scores: Record<string, any>;
    subagent_scores: Record<string, number>;
    is_badcase: boolean;
    flagged_count: number;
  } | null;
  created_at: string;
  decided_at: string | null;
}

interface PromoteTaskDetail extends PromoteTask {
  trace?: { trace_id, status, owner_user_id, started_at, ended_at, duration_ms, session_name };
  deliveries?: Record<string, any>;
  annotator?: string | null;
  decision?: string | null;
  target_case_id?: string | null;
}

// 函数
getPromoteTasks(params?: { status?: string; page?: number; page_size?: number })
  → GET /api/promote/tasks?status=...&page=...&page_size=...
  → { tasks: PromoteTask[]; total; page; page_size }

getPromoteTaskDetail(taskId: string)
  → GET /api/promote/tasks/{taskId}
  → PromoteTaskDetail

decidePromoteTask(taskId: string, payload: {
  decision: "accept" | "reject";
  annotator?: string;
  target_case_id?: string;     // accept 归入已有
  new_case_title?: string;     // accept 新建
  demand_md?: string;          // accept 新建
  reference_output?: string;   // 可选编辑终稿
})
  → POST /api/promote/tasks/{taskId}/decide
  → { task_id, status, case_id?, has_reference? }
```

## 组件结构

```
pages/dataset.tsx                       ← Tab 容器（Radix Tabs）
  <Tabs defaultValue="golden">
    <TabsList>
      <TabsTrigger value="golden">Golden</TabsTrigger>
      <TabsTrigger value="growing">Growing</TabsTrigger>
      <TabsTrigger value="review">待标注</TabsTrigger>
    </TabsList>
    <TabsContent value="golden"><GoldenTab /></TabsContent>
    <TabsContent value="growing"><GrowingTab /></TabsContent>
    <TabsContent value="review"><ReviewTab /></TabsContent>
  </Tabs>

components/dataset/
  ├─ GoldenTab.tsx        ← golden revision 头部 + case 表格 + CaseDetailSheet
  ├─ GrowingTab.tsx       ← case 表格 + 行内升级按钮 + CaseDetailSheet
  ├─ ReviewTab.tsx        ← 待标注表格 + 行内 accept/reject + accept 表单 Sheet
  └─ CaseDetailSheet.tsx  ← 共用详情侧滑（demand.md + reference.md + 元数据 + 可选升级按钮）
```

### 各组件职责

| 组件 | 数据获取 | 刷新策略 | 写操作 |
|---|---|---|---|
| GoldenTab | `getDatasetCases("golden")` + `getGoldenRevision()` | 进入时加载，无轮询 | 无 |
| GrowingTab | `getDatasetCases("growing")` | 进入时加载 + 升级后刷新 | `promoteCaseToGolden` |
| ReviewTab | `getPromoteTasks({status:"needs_confirm"})` | 5s 轮询（对齐 tests.tsx） | `decidePromoteTask` |
| CaseDetailSheet | 无（数据由父组件传入） | 无 | 升级回调透传 |
